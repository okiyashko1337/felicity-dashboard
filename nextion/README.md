# Локальный экран Nextion NX4827P043_011

Этот каталог содержит готовый проект `felicity-dashboard.HMI` для
**Nextion NX4827P043_011**, 480×272, горизонтальная ориентация. Дисплей получает
данные от `nextion_bridge.py` по UART. Веб-панель и сбор данных продолжают
работать независимо от экрана.

## Структура экранов

| ID | Page name | Назначение |
|---:|---|---|
| 0 | `home` | Шесть одинаковых плиток и строка состояния |
| 1 | `pv` | Солнечная генерация |
| 2 | `load` | Потребление дома |
| 3 | `battery` | Аккумулятор |
| 4 | `grid` | Сеть |
| 5 | `system` | Состояние системы |
| 6 | `today` | Энергетика текущего дня |
| 7 | `gaps` | Статистика разрывов текущего дня |

Страницы уже созданы в этом порядке. Мост включает `sendxy=1`, получает
координаты отпускания пальца и сам выполняет переходы. Поэтому проект не
зависит от имён Hotspot-компонентов и его проще расширять.

## Домашняя страница 480×272

Шапка занимает `y=0..43`. Сетка плиток — три колонки и две строки:

```text
┌────────────────────────────────────────────────────────────┐
│ FELICITY       LIVE             01.08.2026      15:09:13 │
├──────────────────┬──────────────────┬──────────────────────┤
│ СОЛНЦЕ           │ ДОМ              │ АККУМУЛЯТОР          │
│ 3100 W           │ 1700 W           │ 50 %                 │
│ PV1/PV2          │ L1/L2/L3         │ 52.4 V · CHG         │
├──────────────────┼──────────────────┼──────────────────────┤
│ СЕТЬ             │ SYSTEM           │ СЕГОДНЯ              │
│ 230.0 V          │ 9.0 % CPU        │ 12.4 kWh             │
│ 0 W · 50.00 Hz   │ RAM · TEMP       │ LOAD · COVERAGE      │
└──────────────────┴──────────────────┴──────────────────────┘
```

Координаты плиток: `x=8/165/322`, `y=50/160`, `w=150`, `h=103`. Мост
использует эти границы при обработке координат касания.

### Динамические данные `home`

Числа и подписи рисуются мостом командой `xstr` поверх фонового изображения.
На экране не требуется создавать отдельные Text-компоненты.

| Component | Содержание |
|---|---|
| `tTime` | тикающие часы |
| `tDate` | сегодняшняя дата |
| `tFresh` | `LIVE` или `NO DATA` |
| `tPvV`, `tPvS` | мощность PV и PV1/PV2 |
| `tLoadV`, `tLoadS` | общая и пофазная нагрузка |
| `tBatV`, `tBatS` | SOC, напряжение и режим батареи |
| `tGridV`, `tGridS` | напряжение, обмен и частота |
| `tSysV`, `tSysS` | CPU, RAM и температура |
| `tDayV`, `tDayS` | выработка, потребление и покрытие за день |

Нажатие на плитку открывает соответствующую страницу. Нажатие на дату в шапке
открывает `gaps`. На детальной странице область `x=0..70`, `y=0..43` работает
как кнопка назад.

## Детальные страницы

На каждой странице `pv`, `load`, `battery`, `grid`, `system`, `today` и
`gaps` находится фоновая картинка `p0` (ID 1) и **Waveform** `s0` (ID 2):
`x=12`, `y=112`, `w=456`, `h=148`, четыре канала.

Числовой блок над графиком содержит главное значение и три дополнительных
показателя. Как и на home, он рисуется мостом через `xstr`.

При открытии страницы числовой блок и часы выводятся первыми. История
прореживается до 45 равномерных точек и затем достраивается небольшими порциями,
поэтому большой график не задерживает появление текущих значений и работу часов.

Цвета каналов Waveform:

- channel 0 — жёлтый, главный ряд;
- channel 1 — оранжевый;
- channel 2 — голубой;
- channel 3 — фиолетовый.

Для `gaps` используется только channel 0. По горизонтали отображаются 96
интервалов по 15 минут от 00:00 до текущего времени. Высокое значение означает,
что данные в интервале были; провал — что они отсутствовали. Над графиком
показываются покрытие суток, число разрывов, самый длинный и последний разрыв.

## Настройка UART

Для плавной отрисовки используется `115200 baud, 8N1`. Заводская скорость
Nextion обычно равна `9600`; один раз отправьте экрану команду
`baud=115200` (с тремя завершающими байтами `FF FF FF`), после чего параметр
сохранится в памяти дисплея. Команды Nextion завершаются тремя байтами
`FF FF FF`.

После прошивки экрана на Mac можно проверить мост без Home Assistant:

```bash
.venv/bin/python nextion_bridge.py \
  --port /dev/cu.usbserial-XXXX \
  --baudrate 115200 \
  --api http://127.0.0.1:8000
```

На Home Assistant OS включите экран в настройках приложения и выберите
стабильный путь `/dev/serial/by-id/...`, а не `/dev/ttyUSB1`: номер `ttyUSB`
может измениться после перезагрузки.

## Проверка до подключения к Raspberry Pi

1. Откройте `felicity-dashboard.HMI` и нажмите **Compile**. Проверенная сборка
   завершается сообщением `Compile Successful! 0 Errors, 0 Warnings`.
2. Загрузите проект на экран из Nextion Editor.
3. Убедитесь, что Waveform `s0` имеет ID `2` на каждой детальной странице.
4. Запустите FastAPI и симулятор Felicity на Mac.
5. Запустите `nextion_bridge.py` с портом USB-UART.
6. Проверьте, что время тикает, `LIVE` зелёный и открытая страница обновляется.

Python-мост автоматически переживает временное отключение USB и повторяет
подключение каждые пять секунд.
